# EWA

EWA — настольное приложение для учёта клиентов и фестивального продвижения фильмов. В нём можно вести карточки фильмов, планировать подачи и отслеживать фестивальные дедлайны.

## Возможности

- **Клиенты и фильмы.** Контакты, документы, карточки фильмов и чек-листы готовности материалов.
- **Каталог фестивалей.** Ручное добавление и импорт из Wikidata, сезоны, сроки подачи и требования к премьере. Для поиска в Wikidata нужен интернет.
- **Фестивальная стратегия.** Заявки по каждому фильму, отслеживание их статусов и экспорт в CSV.
- **Календарь и счета.** Просмотр ближайших дедлайнов, учёт счетов и статусов оплаты.

## Запуск из исходников

Установите Node.js 22 и npm. Выполните команды из корня репозитория.

```sh
npm ci
npm run dev
```

Откроется окно Electron. При запуске приложение применяет миграции SQLite и заполняет пустой каталог стартовым набором фестивалей.

## Сборка

| Команда | Результат |
| --- | --- |
| `npm run build` | Проверка типов и сборка приложения в `out/` |
| `npm run build:win` | Установщик NSIS и портативный `.exe` для Windows x64 |
| `npm run build:win:unsigned` | Те же варианты для Windows с отключённым подписанием и редактированием исполняемого файла приложения |
| `npm run pack:win` | Распакованное приложение для Windows x64 в `dist/win-unpacked/` |
| `npm run build:mac` | Образы `.dmg` для macOS на Intel и Apple Silicon |

Пакеты сохраняются в `dist/`. Для упаковки с настроенными иконками добавьте `resources/icon.ico` для Windows или `resources/icon.icns` для macOS. Требования к файлам указаны в [описании ресурсов](resources/README.md).

## Данные и резервные копии

База SQLite `ewa.db` хранится локально в каталоге данных Electron (`app.getPath('userData')`). Прикреплённые документы лежат в подкаталоге `documents/`.

В боковом меню есть команды «Резервная копия» и «Восстановить из копии». Восстановление заменяет текущую базу и перезапускает приложение. Для полной резервной копии сохраните также каталог `documents/` отдельно от файла базы.

## Структура проекта

Проект использует Electron, Vue 3, TypeScript, Pinia, Tailwind CSS и SQLite (`better-sqlite3`).

- [`src/main/`](src/main/) — главный процесс Electron, доступ к базе и файлам, обработчики IPC.
- [`src/preload/`](src/preload/) — типизированный интерфейс `window.api` для связи интерфейса с главным процессом.
- [`src/renderer/`](src/renderer/) — интерфейс Vue, страницы и хранилища Pinia.
- [`src/main/database/migrations/`](src/main/database/migrations/) — SQL-миграции.
